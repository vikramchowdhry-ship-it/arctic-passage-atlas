How it works

From provider data to a checksummed publication.

Sources

Landsat 8 and Sentinel-1 through Earth Engine, Global Fishing Watch, NASA GIBS, Environment Canada, NSIDC, Open-Meteo.

Processing

Every area, date, threshold and dataset ID lives in one JSON config, with water and coast masks and sensitivity runs.

Evidence

A manifest records the config hash, datasets and a SHA-256 for every output. Tests and a verifier fail the build on mismatch.

Publication

A static site. Demonstration and live modes are labelled on every page, and a mixed site is refused.

Standards

What the project will and will not claim.

No inferred intent

An AIS gap is an event with an unknown cause. An unmatched SAR detection is a detection. Neither is called suspicious or evasive.

Candidates, not findings

A changed pixel is a screening result that needs visual and documentary review.

Gates before publication

Live publication is blocked until ice thresholds are calibrated and change candidates are reviewed.

Limits are part of the result

Cloud cover, polar night, threshold sensitivity and nearshore AIS reception are documented on the method page.
