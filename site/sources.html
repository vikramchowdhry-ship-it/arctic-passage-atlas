Commercial use

Short version: this is a portfolio and research project, not a commercial service.

  • The code is MIT-licensed and may be reused, including commercially.
  • Global Fishing Watch data and outputs derived from it are licensed for non-commercial use (CC BY-NC 4.0). The vessel layer therefore cannot be offered commercially.
  • Earth Engine requires the cloud project to be registered as noncommercial or commercial use. This project uses noncommercial registration.
  • No customers, pricing, accuracy guarantees or service levels are offered or implied.
