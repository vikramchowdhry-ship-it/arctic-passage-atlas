Out of scope

Work this project will not take on.

  • Real-time navigation, ice routing or safety-of-life decisions.
  • Identifying, tracking or targeting specific vessels or people, or describing an AIS gap as suspicious.
  • Commercial products built on Global Fishing Watch data, which is licensed for non-commercial use.

Before you write

Common questions.

Can my company use the code?

Yes. The code is MIT-licensed. The data it uses has its own terms, listed on the Sources page.

Can we use the vessel layer commercially?

No. Global Fishing Watch data and outputs derived from it are non-commercial (CC BY-NC 4.0). Other layers use sources that allow commercial reuse with attribution, but check each one.

Are the analytical layers real results?

Not yet. They are labelled synthetic demonstrations until a provider-backed run passes the publication gates. The live context feeds and the route calculator use real, current data. The status board shows what is pending.

Is there a service level or a price list?

No. Nothing here is a paid service, and no response time or accuracy is promised.
