# Project rules

This repository is a public technical portfolio project. Scientific restraint is more important than dramatic language.

- Never call an AIS gap a dark vessel or suspicious event.
- Never call an unmatched SAR detection a vessel that intentionally disabled AIS.
- Never describe an automatically detected surface change as confirmed construction.
- All displayed observations must be generated by the repository and accompanied by a manifest.
- Demonstration fixtures must remain visibly labelled as synthetic on every page.
- Keep AOIs, dates, thresholds and dataset identifiers in `configs/`; do not hide them in notebooks.
- Check current provider documentation before changing an API endpoint, dataset identifier or band name.
- Keep credentials out of the repository.
